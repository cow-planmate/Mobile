# 📱 모바일 화면 최적화 레이아웃 및 UX 상세 스펙안

모바일 기기는 가로 폭이 좁고(360~430dp) 세로 화면이 제한되어 있어 웹의 모든 요소를 단순히 나열하면 **헤더 영역이 화면의 50% 이상을 차지하는 레이아웃 불균형(UI Clutter)**이 발생합니다. 

이를 방지하고 가장 넓은 컨텐츠 뷰를 확보하면서 모든 기능을 세련되게 담기 위한 **모바일 맞춤형 배치 가이드**를 제안합니다.

---

## 📐 와이어프레임 구조 (한눈에 보는 레이아웃)

```text
+-----------------------------------+  <- Status Bar
|  planMate                [Bell]   |  <- 1. 슬림 헤더 (로고 & 알림만)
+-----------------------------------+
|  [ 검색어 입력... ]  [Grid]  [필터]  |  <- 2. 1행 통합 컨트롤 바 (검색/레이아웃/필터 통합)
+-----------------------------------+
|  전체  #뚜벅이  #극한J  #여유P -> |  <- 3. 횡스크롤 태그 휠 바
+-----------------------------------+
|                                   |  
|  +-----------------------------+  |  <- 4. 메인 피드 리스트 영역 (최대 높이 확보)
|  | [서울]                       |  |
|  |       [카드 썸네일]         |  |
|  | 서울 3박 4일 완벽 여행 코스  |  |
|  +-----------------------------+  |
|                                   |
|                     +-----------+ |
|                     | 🗺️ 지도보기 | |  <- 5. 플로팅 지도 버튼 (하단 중앙 오버레이)
|                     +-----------+ |
|                                   |
|                               (F) |  <- 6. 플로팅 계획 생성 버튼 (FAB, 우측 하단)
+-----------------------------------+
|    [피드]      [일정]    [커뮤니티] |  <- Bottom Tab Bar
+-----------------------------------+
```

## 🛠️ 핵심 배치 전략 및 구현 방법

### 1. 1행 통합 컨트롤 바 (Single-Row Controls)
* **웹 스타일**: 검색창 한 줄, 뷰 모드 한 줄, 필터 버튼 한 줄로 수직으로 나열됨.
* **모바일 배치 제안**: 가로 한 줄에 세 가지 제어 요소를 모두 통합 배치합니다.
  - `[ 검색 인풋 (flex-1) ]` `[ 뷰 토글 아이콘 (36dp) ]` `[ 필터 아이콘 버튼 (36dp) ]`
  - **레이아웃 뷰 토글**: 텍스트("그리드"/"리스트") 대신 단일 아이콘(그리드 모드일 때는 `List` 아이콘, 리스트 모드일 때는 `LayoutGrid` 아이콘)으로 표시하여 가로 폭 공간을 극적으로 절약합니다.

### 2. 가로 스크롤(Horizontal Swipe) 태그 바
* 세로로 줄바꿈(Wrap)을 하지 않고, 단일 행에서 오른쪽으로 밀어서 탐색할 수 있는 `ScrollView`로 감쌉니다.
* 스크롤 인디케이터를 숨겨(`showsHorizontalScrollIndicator={false}`) 공간 효율과 시각적 깔끔함을 유지합니다.

### 3. 바텀 시트(Bottom Sheet) 오버레이 필터
* 상세 필터(지역 선택, 일정 기간 선택, 정렬 기준)는 화면 내에 공간을 두고 확장시키는 대신, 우측 상단 `필터 아이콘` 클릭 시 아래에서 부드럽게 위로 반쯤 올라오는 **바텀 시트(Bottom Sheet)** 모달로 띄웁니다.
* 사용자가 필터를 적용하고 완료하면 시트가 닫히므로 평상시 메인 화면의 여백을 100% 보존합니다.

### 4. 에어비앤비(Airbnb) 스타일의 하단 플로팅 지도 버튼
* 웹의 사이드바 지도는 모바일에서 항상 켜놓기 불가능합니다.
* **모바일 배치 제안**: 피드 리스트 하단 중앙에 투명도가 들어간 타원형의 **`🗺️ 지도보기` 플로팅 단추**를 고정(Absolute Position)시킵니다.
* 이 버튼을 누르면 풀스크린 맵 오버레이가 나타나 마커들을 보여주고, 다시 `목록보기`를 누르면 부드럽게 리스트로 복귀합니다.

### 5. 계획 생성 플로팅 액션 버튼 (FAB)
* 모바일에서 엄지손가락이 가장 쉽게 닿는 영역인 **우측 하단**에 동그란 포인트 컬러 플로팅 버튼(`+`)을 배치하여 언제든 일정 생성을 시작할 수 있는 강력한 CTA(Call To Action) 환경을 구현합니다.

---

> [!TIP]
> **스크롤 반응형 애니메이션 (Advanced UX)**:
> 사용자가 카드를 보기 위해 아래로 스크롤을 내리기 시작하면 **1. 헤더**와 **2. 컨트롤 바**가 상단으로 부드럽게 숨겨지고, 스크롤을 다시 위로 올리면 즉시 나타나는 **Collapsible Header** 기법을 적용하면 모바일의 한정된 화면을 200% 활용할 수 있습니다.
