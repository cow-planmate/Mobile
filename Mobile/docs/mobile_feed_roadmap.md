## 📋 웹 vs 모바일 기능 비교 현황

| 기능 요소 | 웹 (Web) 구현 방식 | 모바일 (Mobile) 구현 현황 | 모바일 구현 방향 |
| :--- | :--- | :--- | :--- |
| **통합 검색** | 검색창 (`SearchBar`) | ❌ 미구현 | 상단 헤더 아래 고정 검색창 탑재 |
| **태그 필터** | 가로 배열 배지 목록 | ❌ 미구현 | 가로 스크롤형 태그 휠 바 배정 |
| **정렬/상세 필터** | 필터 슬라이더 패널 | ❌ 미구현 | 바텀 시트 (Bottom Sheet) 모달 형태로 구현 |
| **뷰 모드 토글** | 그리드 / 리스트 버튼 그룹 | ❌ 미구현 (리스트 고정) | 1열 카드뷰(리스트) / 2열 카드뷰(그리드) 토글 |
| **여행 계획 버튼** | 상단 우측 버튼 & 사이드바 카드 | ❌ 미구현 | 플로팅 액션 버튼(FAB) 또는 헤더 단추 |
| **지도 및 레벨** | 우측 고정 사이드바 | ❌ 미구현 | 별도 하위 모달 또는 전용 지도 탭 전환 |

## 🚀 단계별 구현 로드맵 (순서 제안)

모바일 화면의 좁은 공간적 한계를 고려해 가장 자연스럽고 모던한 순서대로 고도화 로드맵을 구성했습니다.

### 1단계: 검색창 및 계획하기 플로팅 버튼 탑재 (핵심 제어 영역)
- **목적**: 사용자가 검색을 개시하고 직접 일정 생성을 시작할 수 있는 기본 제어권 제공
- **세부 추가 요소**:
  - **검색 바**: 헤더 바로 아래에 돋보기 아이콘과 함께 배치 (실시간 검색 쿼리 연동)
  - **계획 생성 FAB**: 화면 우측 하단에 파란색 포인트 컬러(`#1344FF`)를 가진 동그란 **'계획하기' 플로팅 버튼(FAB)** 배치 (클릭 시 `Home` 스크린으로 이동하여 AI 일정 빌더 실행)

### 2단계: 가로 스크롤 태그 필터 바 구현 (탐색 극대화)
- **목적**: `#뚜벅이최적화`, `#극한의J` 등 성향별 필터링을 한 손 터치로 빠르게 실행
- **세부 추가 요소**:
  - `ScrollView (horizontal)`를 사용하여 화면 양옆으로 넘겨볼 수 있는 라운드 칩(Chip) 바 추가
  - 선택된 태그는 웹처럼 파란색 배경(`bg-[#1344FF] text-white`)으로 액티브 연동

### 3단계: 뷰 모드 토글 및 정렬 바 배치 (목록 레이아웃 제어)
- **목적**: 스크롤 방식(1열로 길게 상세 보기 vs 2열로 촘촘히 썸네일 보기)과 인기순 정렬 설정
- **세부 추가 요소**:
  - 검색창 우측에 조그만 토글 아이콘 배치
  - **리스트형 뷰**: 현재와 동일하게 큰 썸네일 중심 카드 노출
  - **그리드형 뷰**: 2열 그리드 형태로 작고 촘촘하게 썸네일을 렌더링하도록 FlashList의 `numColumns={2}` 설정 스위칭

### 4단계: 바텀 시트 상세 필터 패널 (지역 / 기간 설정)
- **목적**: 웹의 상세 필터 레이아웃을 모바일 한 손 조작에 맞는 UI로 이식
- **세부 추가 요소**:
  - 필터 단추를 누르면 아래에서 올라오는 **바텀 시트(Bottom Sheet)** 레이아웃 노출
  - **지역 선택**: 전체, 서울, 부산, 제주도 등 선택 그리드 칩
  - **기간 선택**: 전체, 1일, 2-3일, 4일 이상 선택 칩
  - 바텀 시트 하단에 '필터 초기화' 및 '필터 적용' 버튼 배치

### 5단계: 모바일 맞춤 지도 오버레이 (웹 사이드바 지도 대체)
- **목적**: 웹의 실시간 지역별 게시글 개수 매핑 지도를 대체
- **세부 추가 요소**:
  - 화면 상단 한 켠에 조그만 지도보기 버튼이나 오버레이를 띄워, 클릭 시 전체 화면 카카오 맵(또는 구글 맵)이 열리고 각 도시에 마커 배지가 표시되는 팝업 모달 구현
